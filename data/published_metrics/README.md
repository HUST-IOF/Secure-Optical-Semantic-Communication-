# Historical aggregate metrics

These CSVs were supplied with the project handoff. They are included unchanged
for traceability, not regenerated by the CPU demonstration.

- `attack_metrics_from_conversation.csv`: 30 rows transcribed from the author's
  full numerical results, covering three conditions and ten leakage counts.
- `lpips_frequency_summary.csv`: supplied frequency-sweep summary (10–70 MHz).
- `lpips_psnr_power_50C_summary.csv`: supplied power-sweep summary at 50 degrees C.

The attack table is an author-provided transcription, not raw training logs.
Consult the source manuscript and original experiment records for the exact
statistics. No new image-quality results are inferred from the waveform demo.
